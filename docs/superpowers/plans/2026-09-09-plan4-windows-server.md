# WinForge Plan 4 — Windows Server (Servidor, IIS, Active Directory) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On Windows Server, WinForge shows a **Servidor** tab (Alt+S) with three categories — *Servidor* (general server tweaks), *IIS* (app-pool/site tuning with backup + Undo, only when the Web-Server role is installed) and *Active Directory* (diagnostic buttons, only on a domain controller) — hides consumer tabs (Jogos, AppX, Win11 ISO), extends the profile/rules/Diagnóstico with a *Servidor* card, and keeps everything testable on a client machine through simulation.

**Architecture:** Server/role detection happens twice: cheap and early (`Get-WinForgeBoostSystemInfo`: `ProductType` + service presence → `$sync.IsServer`, `$sync.ServerRoles`) so the UI can hide/show tabs before the window renders, and in depth in `Get-WinForgeSystemProfile` (`Roles`, new `Server` area) for cards and rules. Entries carry `platform: "server"` and `role: "iis"|"ad"` and are filtered by the existing `Test-WinForgeBoostEntryCompatible`. IIS changes go through one function (`Invoke-WinForgeIisTweak -Name <x> [-Undo]`) that snapshots the previous values to a JSON file before touching anything and restores from it on Undo. Diagnostic buttons run a command in a runspace and show the output in a read-only window. Simulation (`WINFORGE_SIMULATE_SERVER=iis,ad`) lets SelfTest mount the tab headless on a client.

**Tech Stack:** Windows PowerShell 5.1, `WebAdministration` module (IIS provider `IIS:\`), `dcdiag`/`repadmin`/`w32tm`/`netsh`, CIM (`Win32_ComputerSystem.DomainRole`), `Get-SmbServerConfiguration`, WPF; existing build pipeline + SelfTest.

**Spec:** `docs/superpowers/specs/2026-09-07-winforge-design.md` §5.2 (Roles), §5.3 (Server/IIS/AD rules), §5.4 (Servidor tab, hidden tabs, `platform`/`role` fields), §5.6, §7 (IIS risk).

- [ ] **Step 1: Early detection.** In `Get-WinUtilBoostSystemInfo`, after `$sync.OSDisplayVersion`, add:

```powershell
    # ---- Servidor e papéis (barato: ProductType + presença de serviços; o perfil completo vem depois)
    $sync.IsServer = $false; $sync.ServerRoles = @(); $sync.IsDC = $false
    if ($null -ne $env:WINFORGE_SIMULATE_SERVER) {
        # só para testes: "iis,ad" simula um servidor com esses papéis; "" simula servidor sem papel
        $sync.IsServer = $true
        $sync.ServerRoles = @($env:WINFORGE_SIMULATE_SERVER -split ',' | ForEach-Object { $_.Trim().ToLower() } | Where-Object { $_ })
        $sync.IsDC = ('ad' -in $sync.ServerRoles)
    } else {
        try {
            $wfOs = Get-CimInstance Win32_OperatingSystem -ErrorAction Stop
            $sync.IsServer = ([int]$wfOs.ProductType -ne 1)
        } catch { }
        if ($sync.IsServer) {
            $roles = [System.Collections.Generic.List[string]]::new()
            $wfSvc = @{}
            foreach ($s in (Get-Service -ErrorAction SilentlyContinue)) { $wfSvc[$s.Name] = $true }
            if ($wfSvc['W3SVC'])  { $roles.Add('iis') }
            if ($wfSvc['NTDS'])   { $roles.Add('ad') }
            if ($wfSvc['vmms'])   { $roles.Add('hyperv') }
            if ($wfSvc['DNS'])    { $roles.Add('dns') }
            if ($wfSvc['DHCPServer']) { $roles.Add('dhcp') }
            $sync.ServerRoles = @($roles)
            try { $sync.IsDC = ([int](Get-CimInstance Win32_ComputerSystem -ErrorAction Stop).DomainRole -ge 4) } catch { }
            if ($sync.IsDC -and 'ad' -notin $sync.ServerRoles) { $sync.ServerRoles += 'ad' }
        }
    }
    if ($sync.IsServer) { $sync.OSName = "Windows Server" }
```

```powershell
function Test-WinForgeIisAvailable { try { Import-Module WebAdministration -ErrorAction Stop; return (Test-Path 'IIS:\') } catch { return $false } }

function Get-WinForgeIisSnapshotRoot { param([string]$Root) if ($Root) { return $Root }; return (Join-Path $env:ProgramData 'WinForge\iis-backup') }

function New-WinForgeIisSnapshot { param([Parameter(Mandatory)][string]$Name, [Parameter(Mandatory)][hashtable]$Values, [string]$Root)
    $dir = Get-WinForgeIisSnapshotRoot $Root; if (-not (Test-Path $dir)) { New-Item -ItemType Directory -Path $dir -Force | Out-Null }
    $path = Join-Path $dir ("{0}-{1}.json" -f $Name, (Get-Date).ToString('yyyyMMdd-HHmmss'))
    @{ Name = $Name; Date = (Get-Date).ToString('s'); Values = $Values } | ConvertTo-Json -Depth 4 | Set-Content -Path $path -Encoding UTF8
    Write-WinForgeLog -Component "IIS" -Message "Valores anteriores de $Name guardados em $path ($($Values.Count) item(ns))."
    return $path }

function Get-WinForgeIisSnapshot { param([Parameter(Mandatory)][string]$Name, [string]$Root)
    $dir = Get-WinForgeIisSnapshotRoot $Root; if (-not (Test-Path $dir)) { return $null }
    $f = Get-ChildItem $dir -Filter "$Name-*.json" -ErrorAction SilentlyContinue | Sort-Object Name -Descending | Select-Object -First 1
    if (-not $f) { return $null }
    $o = Get-Content $f.FullName -Raw -Encoding UTF8 | ConvertFrom-Json
    $values = @{}; foreach ($p in $o.Values.PSObject.Properties) { $values[$p.Name] = $p.Value }
    return @{ Name = $o.Name; Date = $o.Date; Values = $values; Path = $f.FullName } }
```

`Get-WinForgeIisValue`/`Set-WinForgeIisValue` translate a key: `pool:X:processModel.idleTimeout` → `Get-ItemProperty "IIS:\AppPools\X" -Name processModel.idleTimeout` / `Set-ItemProperty`; `site:X:applicationDefaults.preloadEnabled` → `IIS:\Sites\X`; `server:system.webServer/urlCompression:doStaticCompression` → `Get-WebConfigurationProperty -PSPath 'MACHINE/WEBROOT/APPHOST' -Filter <section> -Name <attr>` / `Set-WebConfigurationProperty`. Values serialized as strings (TimeSpan → `'hh:mm:ss'`, bool → `'True'/'False'`, int → string) and converted back on restore by the setter (WebAdministration accepts strings for these properties).

`Invoke-WinForgeIisTweak`: per `-Name`, build the target key list (all pools from `Get-ChildItem IIS:\AppPools`, all sites from `IIS:\Sites`, or the server-level section), read current values into a hashtable, `New-WinForgeIisSnapshot`, then set the new values; `-Undo` → `Restore-WinForgeIisSnapshot` (if no snapshot: message "sem backup para desfazer" and `Changed = 0`). Targets:

| Name | Keys → new value |
|---|---|
| AlwaysRunning | `pool:*:startMode` → `AlwaysRunning`; `pool:*:autoStart` → `True` |
| NoIdleTimeout | `pool:*:processModel.idleTimeout` → `00:00:00` |
| MemoryRecycling | `pool:*:recycling.periodicRestart.time` → `00:00:00`; `pool:*:recycling.periodicRestart.privateMemory` → KB = clamp(floor(TotalRAM_KB × 0.6 / poolCount), 1048576, 8388608) |
| Preload | `site:*:applicationDefaults.preloadEnabled` → `True`; skipped with message when `Web-AppInit` is not installed (check `Get-WindowsFeature Web-AppInit` when available, else attempt and catch) |
| Compression | `server:system.webServer/urlCompression:doStaticCompression` → `True`, `:doDynamicCompression` → `True` (dynamic skipped with message when `Web-Dyn-Compression` missing) |
| OutputCache | `server:system.webServer/caching:enabled` → `True`, `:enableKernelCache` → `True` |
| Concurrency | `pool:*:queueLength` → `5000`; plus registry (in the entry, not here) |
